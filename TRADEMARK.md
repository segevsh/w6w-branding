# Using the w6w name and mark

This repository is public so that people writing about w6w, packaging it, or building on it can
get the assets right. Publishing the files is not a licence to use the mark as your own.

> **Status, stated plainly:** the `w6w` trademark has **not** been searched or registered. This
> policy describes how we ask people to use the name; it is not a claim that a registration exists,
> and we would have to clear the mark before enforcing any of it.

## You don't need to ask

- Using the logo to **refer to w6w** — a blog post, a talk, a comparison table, a "works with w6w"
  line in your README, a slide.
- Linking to us with the mark, unmodified, from the files in this repo.
- Saying your product **works with**, **is built on**, or **integrates with** w6w.
- Redistributing the software under the licence that software carries. That is governed by the
  `LICENSE` file in the repo you got the code from, not by this document.
- Community things that are obviously community things — a meetup slide, a fan diagram, a
  conference sticker — as long as nobody could mistake them for something we published.

## Please don't

- Use the mark, or a name confusable with `w6w`, as **the name or icon of your own product,
  service or company**, or in your domain, app-store listing, or social handle.
- Modify the mark — recolour, redraw, add to it, or extract the `6` into a new logo — and keep
  calling it ours.
- Lock our mark up with yours in a way that implies a partnership, endorsement, or a joint
  product, unless we have actually agreed to one.
- Use it on merchandise for sale.
- Register it, or anything confusable with it, as a trademark or domain anywhere.

## The test

**Would a reasonable person seeing this think w6w made it, or endorsed it?** If yes, ask first.
Everything above is that one question worked through the common cases.

## Forks

Fork the code freely under its licence — but **give the fork its own name and its own icon**. You
may factually say it is "a fork of w6w"; you may not ship it *as* w6w. This is the ordinary
open-source convention and it protects users of both projects.

## Asking

Anything this document doesn't cover, or a case where you think the answer should be yes: open an
issue on this repository. Reasonable requests get reasonable answers.
